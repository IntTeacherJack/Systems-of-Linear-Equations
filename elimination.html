Solar lantern programme

Elimination

Two equations can reveal two unknowns. Find the number of each lantern supplied.

☀
The challenge

Light for learning

A community learning programme supplied 80 solar lanterns. Model A costs $12 and Model B costs $18. The total cost was $1,152.

How many lanterns of each model were supplied?

1 · Model the situation

What do you know?

Let a be the number of Model A lanterns and b be the number of Model B lanterns.

a + b = 80 total lanterns

12a + 18b = 1152 total cost

There are two equations and the same two variables. We can make one variable disappear, then solve for the other.

2 · Make a prediction

Which model was supplied more often?

Model B costs more. Pause before calculating: which model do you think was supplied more often?

3 · Learn the method

Eliminate one variable

01

Match a coefficient

Multiply every term in the first equation by −12.

−12(a + b = 80)−12a − 12b = −960
02

Add the equations

Write the new equation above the cost equation. Add each column. The a terms cancel because −12a + 12a = 0.

−12a − 12b = −960
+ 12a + 18b = 1152
0a + 6b = 192
6b = 192, so b = 32
03

Solve and substitute

Put b = 32 into a + b = 80.

a + 32 = 80a = 48, b = 32

4 · Check your thinking

Does the solution work?

Enter the numbers of Model A and Model B lanterns. The checker will test both original conditions.
